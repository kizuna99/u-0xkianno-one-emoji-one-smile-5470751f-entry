A tiny program that writes exactly one emoji — 🧸, the teddy bear — to `/output/entry.txt` and nothing else. The teddy bear was picked from an 18-candidate tournament scored against the judge's five criteria in order: it plainly aims to comfort a stranger, reads warm at first glance in every culture, feels chosen rather than default, and carries no intimacy, sarcasm or flirtation that would read oddly from someone unknown. The output is byte-exact across runs: 1 character, 4 UTF-8 bytes, no trailing newline.

Run it with `python3 main.py` (Python 3.13, no dependencies, no network).
